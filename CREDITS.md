# Credits

## Quad model

`public/models/fpv-drone.glb` is based on "Fpv Racing Drone Quadcopter" by eagleanurag
(https://sketchfab.com/eagleanurag), licensed under CC BY 4.0
(http://creativecommons.org/licenses/by/4.0/).

Source: https://sketchfab.com/3d-models/fpv-racing-drone-quadcopter-fa8b1ca2695e4022a9b4c70401f04b05

Changes made: meshes and textures compressed into one GLB (meshopt, WebP), frame material
darkened in code, props recoloured per pilot in code, model scaled to a 225 mm wheelbase.

The licence asks for credit wherever the model is shown. The game shows the credit line on
the home screen. Keep it there.

Note: the copy used here was taken from a public GitHub repository that carried the
Sketchfab licence file with it. A second Sketchfab upload of the same mesh exists under
another account, also marked CC BY 4.0. Check the Sketchfab page yourself before a
commercial launch.
